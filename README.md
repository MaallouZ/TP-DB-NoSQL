# NoSQL Assignment — Digital Library (MongoDB)

NoSQL database assignment modeling a digital library (books, authors, users, loans) with MongoDB.

## Contents

- `TP.md` — assignment statement
- `1-inserts.js` — data insertion
- `2-selects.js` — select queries
- `3-agregate.js` — aggregation pipelines
- `4-update.js` — updates
- `5-delete.js` — deletions
- `6-join.js` — joins (`$lookup`)
- `7-advanced.js` — advanced queries
- `8-arrays.js` — array manipulation

## Usage

In `mongosh`, connected to the `bibliotheque` database:

```js
load("1-inserts.js")
load("2-selects.js")
// etc.
```
